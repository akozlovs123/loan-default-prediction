# loan-default-prediction
Student project using SBA loan data to predict whether a loan will default

## About this project
In this notebook I cleaned the data, analyzed it and prepared the dataset for modelling.
My goal was to predict whether a loan will be paid back or default.

#Summary of the work done
-Cleaned and prepared the loan data
-Looked for missing values and unusual entries
-Converted the data into a usable format
-Used visualizations to better understand the data
-Created a target variable for loan default

## Tools used
-Python
-Pandas
-Numpy
-Matplotlib
-Seaborn
-Jupyter Notebook

## My motivation for choosing this project
Throughout my studies, I learned a lot about machine learning and working with datasets. I wanted to apply that knowledge and practice data cleaning, analysis and prediction techniques on a real world financial dataset.
